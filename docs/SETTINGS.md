# Settings

Run `DakoSettings.exe` beside `Dako.exe`, or choose Settings from the island menu. The independent native
window works while the island is closed. Search filters the schema across all pages. Apply commits staged
changes; visual controls preview immediately, and sliders commit their value on release. Closing or losing
the settings process discards uncommitted previews. Reset page/all stages defaults for review before Apply.

The curated schema has 36 preferences plus reset/import/export. Advanced contains safe mode, diagnostics
and the existing optional feature controls. There is no mascot, signing requirement or web runtime.

## Persistence and synchronization

`SettingsStore.h` owns `%LOCALAPPDATA%\Dako\settings.ini`, a bounded UTF-16 schema-4 document. Version-3
documents migrate while preserving legacy settings. The first V4 migration enables Offline. Preview mode
reads preferences without migration or writes. A per-user cross-process mutex serializes writers; updates
reload the document, flush a staging file, then replace atomically. Future schemas cannot be overwritten.
Malformed current files are preserved as `.corrupt-<timestamp>` backups before defaults are created.

The settings application and island share `dako_core.lib`. A user-scoped named event signals commits;
registered waits replace settings polling. A local-only, per-user ACL-protected named pipe carries bounded
live previews. The island watches the sender process and rolls back if it closes or crashes. Only schema
entries marked live accept preview packets. Preview values are never persisted by the island.

Export includes private calendar URLs and snippets in plain text. Import validates version, size, duplicate
keys, types and ranges; it backs up the old store, discards imported module consent, preserves taskbar consent
and cannot disable an active Offline preference. Clipboard snapshots and recovery journals are not exported.

## Taskbar, startup and network

Ordinary startup displays the app island without reserving work area. Replace taskbar requires the separate
desktop consent/recovery flow. A layout choice or import cannot grant it. Ctrl+Alt+Shift+T restores Explorer;
Ctrl+Alt+Shift+Q exits. Start with Windows manages only this user's Dako value in the Windows Run key and
points to this portable folder. Move the folder before enabling startup, or toggle startup after moving it.

Weather needs a city and Offline disabled. Speed testing needs its opt-in, Offline disabled, and an explicit
Run speed test action. Calendar feeds still use the existing Today options. Native Windows Settings launches
and other applications have their own network behavior.

## Troubleshooting

Use a writable export location and retain corrupt-file backups while investigating. Failed atomic writes keep
the previous committed file. Diagnostics exports omit private text settings, URLs, app lists and local paths.
To restore a retained system-effect journal, reconnect the hardware and use `Dako.exe --restore-session="path"`
for a journal under `%LOCALAPPDATA%\Dako\Recovery` whose owning process has exited.

Features manages optional modules, presets and capabilities. Disabled modules release workers, subscriptions
and timers. See [privacy](PRIVACY.md), [architecture](ARCHITECTURE.md) and [verification](VERIFICATION.md).
